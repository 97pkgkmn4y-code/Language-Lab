# Language Lab — Obsidian & GitHub

Vault для обучения польскому B2 и английскому для оценки ответов ИИ. Открой папку в Obsidian как vault; стартовая страница: `00_START_HERE.md`.

- Markdown и YAML frontmatter, без сторонних плагинов.
- Полный план: `01_Program/`, фактические уроки: `02_Sessions/`, повторяемые ошибки: `03_Errors/`.
- Контроль и источники: `04_Reviews/`, `05_Sources/`.
- Правила ведения: `06_Protocols/`, шаблоны: `07_Templates/`.
- Прошлые исходные версии храним в `09_Archive/`.

**Безопасность:** репозиторий рекомендуется **Private**. Не загружай в него купленные PDF/аудио, персональные документы, секреты, ключи, аккаунты. Книги хранить локально вне Git, здесь только ссылки и страницы. GitHub не синхронизирует текущий чат автоматически.

См. `GITHUB_SETUP.md`.

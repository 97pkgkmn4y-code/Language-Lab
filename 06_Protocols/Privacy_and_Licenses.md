# Приватность и лицензии

- GitHub репозиторий рекомендуется `Private` — журнал содержит персональные сведения, даже если без секретов.
- Не размещать паспортные данные, реальные контакты, логины, токены, банковские данные, медицинские сведения, закрытые экзаменационные материалы.
- Купленные PDF/EPUB/audio и рабочие материалы внешних компаний не коммитить; `.gitignore` исключает распространённые форматы, но файлы перед коммитом проверяются вручную.
- GitHub private — не абсолютная гарантия: доступы, форки, утечки и история коммитов требуют контроля.
- Для ChatGPT Projects: репозиторий не является автоматически обновляемым источником. Прикладывать актуальные файлы / подключать разрешённые интеграции и подтверждать доступ.

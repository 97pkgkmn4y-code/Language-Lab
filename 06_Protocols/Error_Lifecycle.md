# Жизненный цикл ошибки

## Статусы
- `NEW`: впервые обнаружена, ещё не отобрана в программу.
- `ACTIVE`: важная или повторяющаяся ошибка; назначены повторения.
- `REVIEW`: минимум **2 корректных самостоятельных использования в разные даты** без переводчика/подсказки.
- `MASTERED`: минимум **3 корректных использования в разные даты**, включая одно минимум через **7 дней после первого успеха**; без повторного нарушения в недавней диагностике.

## При ошибке снова
Понизить до ACTIVE, записать точную ошибку, контекст, дату и следующее повторение. `MASTERED` не означает «навсегда забыто».

## Доказательства
Для каждого случая: дата, ссылка на сессию, исходный ответ, исправление, был ли переводчик/ИИ. Подсказанный ответ **не засчитывается** как самостоятельное успешное применение.

## Повторы
Предложение: следующий день, через 3 дня, через 7 дней, затем раз в месяц для освоенных. Это эвристика, не научно подтверждённый оптимальный интервал для конкретного человека.

## История
Не удалять карточку после освоения, не переписывать дату первой ошибки, сохранять события внизу карточки. Git история служит резервным следом изменений.

# Учебный контракт

- Польский: экзамен państwowy B2 весной 2027, дата будет уточняться по официальным источникам. Приоритет: письмо, грамматика, устная речь, чтение, слушание.
- Английский: базовое письмо/чтение A2 → B1; рабочая цель: читать инструкции AI Evaluator, находить все требования, объяснять решения ясно и самостоятельно.
- Ежедневно: 30+30 минут, план по **7-дневному циклу**, фиксировать реальную длительность только если измерена.
- Пропуск не надо «отрабатывать» двойной нагрузкой. Возобновить обычный ритм.
- Использование словаря отмечать отдельно; для диагностики проводить короткие пробы без помощи.
- Целевое улучшение подтверждать **повторными разнородными заданиями**, не по одному баллу.
- Книги — структура обучения, ошибки — система адаптации.
